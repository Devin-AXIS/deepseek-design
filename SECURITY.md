# Security

Report vulnerabilities privately through the repository's GitHub security advisory channel. Do not include API tokens or private project content in public issues.

Document HTML and downloaded components execute in isolated document frames. They do not receive Host API credentials. Owner-authenticated editor endpoints confine file access to original Design/Video directories in the selected registered workspace. They are not model-tool permission checks. The model-facing video checker selects its project from the active agent session. Remote resource APIs require HTTPS except for explicit loopback development services. Executable component content remains subject to its provider's trust and license requirements.

A DSH process owner can edit files on their own computer. Plugin code and client restrictions do not create an operating-system security boundary or make enterprise software tamper-proof. Organizations requiring protected policies must enforce them at the Host/process and deployment layer.
