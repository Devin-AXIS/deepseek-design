# DeepSeek Video

iPolloWork 的独立原生视频工作台，沿用已有时间线、文件、素材、主题及 MP4 导出。左右入口可在 DSH 插件设置分别配置。

打开「视频模板库 → 动效参考」，可按用途、动效、品牌、行业、创作模型、颜色、画幅和时长浏览、搜索并预览 OpenMotion 的公开目录。可下载工程会复制到新会话，经现有 Video 引擎验证后打开。参考片只用于测量和重制；不是现成的可编辑工程。

在已有视频中点击「参考复刻」，可上传获准使用的 MP4、MOV、WebM 或 MKV，或粘贴公开可下载的 HTTPS 视频链接。站点仅支持登录或流式播放时，使用授权的本地文件。导入保存参考片及 MOTION.md，不替换画布；将简报带到原生会话，利用现有工具测量、重建可编辑图层并导出。

运行 `npm run snapshot:motion` 再构建可包含离线目录元数据；不分发第三方工程源码、视频或标识。原内置、个人和组织模板入口不变。
