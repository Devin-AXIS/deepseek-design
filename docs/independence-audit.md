# 独立插件审查（beta.4）

审查对象是本仓库的 Design（包含 PPT）和 Video 两个插件、共享源码、构建脚本、运行资源及 CI。目标是独立安装和运行、明确前后端职责，并删除已经退出调用链的旧应用代码。编辑器和文档格式继续沿用迁入的实现；代码来源和许可证仍然保留。

## 已修复

| 问题 | 修正 |
| --- | --- |
| 前端创建旧应用的完整服务客户端，包含大量本插件没有实现的方法 | 改为 `StudioServiceClient`，只声明本插件实际提供的 16 个服务方法，保留真实文件、模板、媒体和动作接口 |
| 旧桌面桥接、账户、OpenCode/Den 客户端通过运行时或类型导入继续关联 | 改为本地 Studio 类型与浏览器能力；移除无引用的整条旧模块链 |
| 媒体工作台依赖缺失的 PlatformProvider | 使用独立平台适配；浏览器选图、字体访问和录音直接使用对应浏览器能力 |
| 媒体生成刷新旧全局 QueryClient、主题读取旧应用 DOM 属性 | 使用当前编辑器的 QueryClient 和 DSH 原生主题订阅 |
| 模板读取失败被当作没有文件 | 显示实际错误并提供重试 |
| 模板和视频资源回退到旧 App 安装目录、全局组件库 | 只读取随插件发布的显式资源目录；导入组件属于当前工作区 |
| provider fetch 读取旧 Electron 全局注入 | 使用原生 fetch，保留超时、取消和错误翻译 |
| 卸载时可能先关闭存储，再等待已接收请求 | 停止接收、取消外部工作、等待请求和流结束，最后释放存储；卸载后清理凭证实例和音频缓存 |
| 模板兼容版本可能误用新插件版本 | 独立记录已支持的旧模板能力版本 `0.50.34`，拒绝要求更高版本的模板 |
| 拆分编译配置后 JSX 编译依赖隐式根配置 | 固定浏览器编译配置与自动 JSX 模式；回归测试直接渲染两个编译后导航组件 |
| CI 归档安装缺少 pnpm，失败后曾改用源码链接 | 安装固定版本 pnpm；验证必须使用真实 `.tgz`，不再降级为源码链接 |

## 清理范围

删除 582 个已不再使用的源码、旧元数据及主题资源文件，其中 543 个是未被运行时或保留指南引用的主题翻译、默认令牌副本和预览图片。删除主题资源约 8.50 MB；其余删除项包括旧客户端、桌面桥接、会话引擎、旧 MCP/proxy 管理、无引用 UI 模块和旧服务器安装清单。源码清单随删除同步更新，保留文件的原始摘要与本地修改分别记录。

保留所有 151 套主题的实际运行数据、设计/使用指南，以及指南引用的组件清单、示例和报告。保留原 Design/PPT/Video 编辑器、模板、媒体工作台、HTML 文档和 HyperFrames。没有依据名称删除业务功能；HyperFrames 是随插件构建的第三方运行时，不是旧应用服务器。

清理了无引用的 OpenCode SDK、JSONC、minimatch 和旧着色器直接依赖。DSH 的 locale、store、session 和 controller 类型依赖需要为原生插槽提供声明，不能仅因为没有显式运行时 import 就删除。

## 后续维护规则

`tsconfig.host.json`、`tsconfig.studio.json` 和 `tsconfig.test.json` 分开检查；生产 Host 不带 DOM 类型，Client 不加载 Node 全局类型。`npm run check:boundaries` 从两个插件入口和真实动态入口检查运行时导入，拒绝前端读取 Node/服务器模块、Host 导入 UI、重新依赖旧应用入口或源代码逃出仓库。共享 JSON/文档类型不作为可执行模块处理。

构建前清理各插件的 `lib`，避免旧产物进入安装包。源码摘要检查同时覆盖新增适配文件；真实安装测试验证归档来源、包名及版本。CI 的 `STUDIO_SMOKE_APPROVE_RUNTIME_BUILDS=1` 只在隔离测试 profile 中授权列明的确切依赖版本，本地默认不会授权。

## 明确的能力限制

HeyGen 的 API-key 路径保留。原订阅模式的业务实现仍在，但订阅登录和回调尚未接入 DSH，不能称为已经可用。付费图像、视频、配音和数字人服务仍需要真实提供方凭证；离线增强需要另行配置模型。

本轮证明独立构建、安装、依赖分层及所测交互，并不等于所有旧工作流已逐项验收。原 iPolloWork 的运行进程、后台、账户客户端和源码目录都不是安装依赖；原代码来源与 Source Available 许可证仍须保留。

Video 在 390px 窄屏下仍沿用原桌面多栏工作台，存在横向空间不足；本轮仅验证并记录，没有重做原版工作台布局。
