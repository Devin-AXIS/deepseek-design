# Beta.3 native verification

Verified locally on DSH 0.2.2-rc.2 and Node 24.9+. `npm run check` passed the native builds, separate Host/Client typechecks, 21 focused tests, package payload checks and hashes for 2,491 captured source files with 39 recorded adaptations. The concurrent-save regression also passed 20 repeated runs after fixing timestamp rounding. A clean export of the staged source also passed `npm ci --ignore-scripts --no-audit --no-fund` and `npm run check`, including rebuilding HyperFrames without existing build output. Hosted CI has not run.

The supported DSH launcher exercised Design alone, Video alone and both together in disposable profiles. All three native archive installs requested build-script consent for runtime dependencies. No scripts were approved. Each case then passed through native source links, including owner authorization, anonymous denial, stale capabilities and removal of the old enclosing editor page. Those development-profile checks used source links. At the user’s subsequent explicit request, both final beta.3 archives were installed in the active ipw-visual profile using its existing dependency-build approvals. Design replaced beta.1, both bundles were enabled, and DSH restarted at port 50956. The installed packages contain native mounts and no enclosing editor page. The current window opened the original Design canvas and Video workbench; the Design catalog returned 35 templates. Existing projects and the native profile configuration were backed up or retained.

Browser inspection confirmed that the original editor components mount directly in the DSH document. No enclosing editor iframe exists. Original HTML previews and the HyperFrames workbench retain their embedded document rendering. The original Design template picker applied the 38-slide iPollo VI presentation. A canvas ResizeObserver defect was corrected and the real scaled canvas rendered. Light/dark themes and 390px layout were inspected; original dark palette selectors now apply at the scoped editor root. Native placement controls removed and restored the left entry. Service credential-reference settings rendered in native plugin details.

The original template workflow passed initialize, apply, validate, save, .ipwp export, list and reapply tests. Adoption of existing original HTML retains both document bytes and its selected entry. Parallel native saves with the same loaded revision accept one writer and reject the stale writer. Resource transport tests cover stale-token recovery without duplicate mutation, byte integrity, cancellation and workspace escapes. Native service tools bind to the active registered workspace/session and honor DSH read-only access.

The original Video workbench displayed script, preview, timeline and property controls. Changing a text layer updated the preview and the original saved HTML, then the QA text was restored. The original narration panel received native service status without request-validation errors. The original enhancement panel received an explicit missing-offline-model status. This machine has not provisioned those model weights, and no paid voice, image, avatar or video generation was performed.

The original Design UI exported a 38-slide PPTX containing 600 editable text runs. LibreOffice rendered representative slides 1, 2, 10, 20 and 38. Inspection found lost CSS nowrap on a short page number; the exporter now preserves it, the exported XML contains wrap=none, and a second actual UI export rendered that number on one line. Slide 20 was pixel-identical after this change. Fonts remain external to the PPTX; QA used the template-provided Poppins/Syne fonts in a temporary process configuration, without installing system fonts. This does not establish identical rendering on machines without those fonts or acceptance of every export mode.

The suite's default catalog now carries the same final beta.3 archives with SHA-256 filenames. A separate snapshot of the current suite passed `npm run check` with 47 tests passed and five native integration skips, plus `npm run pack:check` and package creation. The tested suite archive was copied to the suite root after checking that the source had not changed. That isolated package check did not rebuild the working suite. The later user-authorized editor installation and restart are recorded above.

Full original workflow parity remains subject to configured-provider, authorization and resource acceptance. Registry publication and production rollout have not been performed.

The repository now carries independently maintained plugin source. The former iPolloWork forward-sync and reverse-import GitHub workflows were disabled before replacing the mirror, so later upstream builds cannot overwrite this source tree.
