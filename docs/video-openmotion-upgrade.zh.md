# Video 插件升级与 OpenMotion 对照验收

Video 继续覆盖从脚本、分镜、素材到正片导出的完整流程。DSH 插件入口、编辑器顶部和工作区、组件库、个人和内置模板、主题与品牌素材，以及已有工程格式都作为升级的兼容基线。

## 引擎和编辑器

OpenMotion 以 HyperFrames Studio 为基础开发编辑器，使用 HTML、CSS 和 JavaScript 保存可编辑工程，通过浏览器逐帧渲染并由 FFmpeg 编码。参考片复刻会先记录镜头、转场、运动、字体、颜色和声音，再重建可编辑图层，按相同时间点比较并修正。脚本适合记录叙事、分镜和文案。对象的运动与声音时点需要来自参考帧、区域测量和实际试听。[OpenMotion 工作流](https://github.com/nexu-io/openmotion#from-a-reference-to-an-editable-project)

Work 现有 Studio 基于定制的 HyperFrames 0.8.140。对比官方 0.9.84 时，共有 307 个文件的上游与 Work 改动需要处理，216 个在 Studio。现有导出的独立采集尺寸、成片尺寸和手工编辑注入也需要兼容验证。Beta.25 先将官方 0.9.84 的测量命令独立打包进 Video，由 DSH 会话调用。工作台的预览和导出继续使用现有定制引擎。[HyperFrames 0.9.84](https://github.com/heygen-com/hyperframes/releases/tag/v0.9.84)

## 开发与验收顺序

| 阶段 | 交付范围 | 验收 |
| --- | --- | --- |
| 1. 编辑与测量 | 从保存的源文件复制片段和特效，支持独立的效果目标、时间和撤销历史。接入切点、视听事件、运动曲线、色彩、文字与同时间点帧比较 | 安装真实插件包，用已有模板和含声音的工程验证分镜、时间线、特效、组件、主题、复制、保存、撤销和成片导出 |
| 2. 新版 Studio 与导出 | 把 Work 的手工图层编辑、音视频资源、组件绑定、主题、预览与导出参数迁到新版引擎适配层 | 用同一批旧工程双跑，比较多宽高比、缩放、帧率、透明度、音轨、转场、字幕和 3D。打开旧项目后比对保存前后的素材与依赖 |
| 3. 参考片到完整制片 | 贯通本地或授权链接素材、镜头证据、可编辑复刻、品牌替换、配音字幕、候选素材采纳、版本和最终导出。接入模板说明及可复用项目 | 同一输入和简报分别走 OpenMotion 与 Work，从素材独立生成工程。逐个核对镜头、文字、关键帧、声画同步和可编辑性，再核对正常速度的全片观感 |
| 4. 其余能力对齐 | 验证模板浏览、下载与复用，模型配置与图片/视频/音乐/语音生成，版本恢复和工程分享。将实测 OpenMotion 操作补入用例 | 用覆盖实际工作流的影片验收，包括纯动效、产品 3D、课程讲解、实拍与生成混剪、有旁白和字幕的影片。每个用例记录输入、版本、差异和结果 |

## Beta.25 安装包验证

在 macOS 的临时 DSH 0.2.2-rc.3 配置中验证了独立安装及与 Design 联合安装。一个含 GSAP 和音轨的工程经过复制、撤销和重做，将副本的淡入从 0.65 秒改为 0.70 秒，原件保持 0.65 秒。由编辑器导出的 720p MP4 已完整解码，测试音在计划的第 1 秒开始。原生会话中的测试模型随后调用 Video 的 Skill 和测量工具，从这份成片取得两张指定时点的 PNG。浏览器还检查了组件库、主题、模板套用和 390px 预览布局。

## 已取得的引擎对照样本

两组测试均由 OpenMotion 0.9.7 和官方 HyperFrames 0.9.84 读取相同的 Work 模板工程，以 1920×1080、12 fps 编码。用 FFmpeg 解码再逐帧比较。

| Work 模板 | 对照结果 |
| --- | --- |
| Course Journey，20 秒、240 帧 | 平均 PSNR 约 57.5 dB。旧 Work 渲染在同源对照中存在可见的布局差异 |
| App Device Launch，15 秒、180 帧 | 两份输出的解码画面逐帧一致 |

这些结果证明两个版本对这两份现成工程的渲染接近。参考片从零复刻的端到端质量、全片声音与版本恢复仍需按上表独立验收。
